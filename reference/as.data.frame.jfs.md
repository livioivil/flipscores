# Coerce jfs to data frame

Coerce jfs to data frame

## Usage

``` r
# S3 method for class 'jfs'
as.data.frame(x, row.names = NULL, optional = FALSE, ...)
```

## Arguments

- x:

  A `jfs` object.

- row.names:

  Ignored.

- optional:

  Ignored.

- ...:

  Additional arguments (currently unused).

## Value

A data frame with all summary tables stacked, with a `Model` column
prepended.
