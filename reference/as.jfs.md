# Coerce to jfs objects

Generic function to coerce objects to class 'jfs'.

Coerces an `fs_contrasts` object to class `jfs`.

## Usage

``` r
as.jfs(x, ...)

# Default S3 method
as.jfs(object, ...)
```

## Arguments

- x:

  an object of class `fs_contrasts`

- ...:

  further arguments (currently unused)

## Value

an object of class `jfs`
